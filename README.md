# HNG Stage 0 — Testable Profile Card

A simple, responsive, and accessible **Profile Card** built with **HTML, CSS, and JavaScript** for the HNG Internship Stage 0 task.

🔗 **Live Demo:** [View Here](https://profilecard-hng-0.netlify.app/)

---

### ✨ Features
- Semantic HTML structure  
- Responsive layout (mobile to desktop)  
- Real-time display of current time in milliseconds  
- Profile image, bio, social links, hobbies, and dislikes
