# 🌟 HNG Stage 0 & 1 — Testable Profile + Contact Form Web App

A **multi-page, responsive, and accessible web project** built for the **HNG Internship Stage 0 and Stage 1 tasks**.  
It includes a **Profile Card page** (Stage 0) and a **Contact Form page** (Stage 1) and **about me page**, both designed with semantic HTML, CSS, and vanilla JavaScript.

---

## 🚀 Live Demo
🔗 [View Live Here](https://profilecard-hng-0.netlify.app/)

---

## ✨ Features

### 🧩 Stage 0 — Testable Profile Card
- Semantic HTML layout  
- Responsive design (mobile to desktop)  
- Displays real-time current time in milliseconds  
- Profile image with descriptive `alt` text  
- Includes name, bio, and role  
- Social media links (GitHub, LinkedIn, Twitter, etc.)  
- Lists of hobbies and dislikes  
- Lightweight styling using pure CSS  

### 📨 Stage 1 — Contact Form Page
- Fully responsive and accessible design  
- Semantic HTML structure for form elements  
- Real-time validation for all fields (name, email, subject, message)  
- Animated red border around invalid input fields  
- Descriptive error messages displayed dynamically  
- Success modal shown upon valid form submission  
- “About Me” page with story, goals, reflections, and future dreams  
- Uses a small icon library (Remix Icon) for minimalist design  

---

## 🧠 Tech Stack
- **HTML5** — Semantic and accessible structure  
- **CSS3** — Custom responsive styling  
- **JavaScript (Vanilla)** — Real-time logic and modal handling  
- **Remix Icon** — Lightweight icon set
